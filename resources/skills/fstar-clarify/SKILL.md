# Clarify

Use after planning-review authorization. Inspect specs, code, tests, and configuration before asking answerable questions. Explore one decision dependency at a time; distinguish facts, proposals, confirmed conclusions, open questions, and superseded conclusions. Maintain clarify.md yourself using the task template. Put multi-source comparisons, protocols, or probes in research/ using the research template. Pass only explicit conclusions to doc and plan.
